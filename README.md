# UPSC CSE 2028 Research Dataset

Research repository for the UPSC CSE 2019–2025 AIR 1–5 topper dataset, evidence registry, cleaned analysis data, and pattern-analysis outputs.

Primary population: AIR 1–5, CSE 2019–2025 (N=35 candidate-year-rank observations).

Data protocol: raw → verified → cleaned → analysis → patterns → later decision-support layers.

Missing-data states are preserved; conflicts are never silently resolved.
